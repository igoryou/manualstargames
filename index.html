Palavras que você vai ver

Joystick

A alavanca. Move para cima, para baixo, para a esquerda e para a direita.

Botões A a H

Os botões de ação do jogo. Cada um tem uma cor, como no topo desta página.

1P Start

O botão Start do Jogador 1. Nos menus, abre opções, confirma e volta.

Botão Setting

Um botão pequeno na lateral da caixa da placa. Abre o menu de configuração.

Menu

Uma lista de opções que aparece na tela.

Moeda ou crédito

No modo moeda, é preciso inserir moeda para jogar. No modo Free play (modo família), não precisa.

Dica de ouro
Em quase todas as telas de configuração, o botão 1P Start volta para a tela anterior. Se errar, é só voltar.

Trocar o tamanho da imagem

A placa tem 3 tamanhos de imagem. O padrão é 1280×720. Troque se a imagem não combinar com a sua tela.

  1. Com a placa desligada, aperte e segure o botão Setting.
  2. Sem soltar, ligue a energia.
  3. Conte 2 segundos e solte o botão.
  4. Repita os passos 1 a 3 para ir ao próximo tamanho.

Como abrir: aperte o botão Setting, no menu de jogos ou durante um jogo.

Na dúvida, não mude
Se não tiver certeza do que uma opção faz, deixe como está. Para desfazer tudo, use Factory Setting (item 5.6).

5.1 Testar os botões (IO Test)

Serve para ver se os botões e a alavanca funcionam. A tela mostra o painel do Jogador 1 (esquerda) e do Jogador 2 (direita), com os botões A a H, o Start, a moeda (Coin) e a pausa (Pause). Aperte um botão e veja se ele responde na tela.

5.2 Mudar qual botão faz o quê (Custom Button)

Você pode escolher qual botão físico será o A, o B, e assim por diante.

  1. Entre em Custom Button. No alto da tela há três abas: Arcade Button Mapping (botões do painel), Game Controller Mapping (controle USB) e Restores Default Custom Button (voltar ao padrão). Use o joystick para esquerda ou direita para escolher a aba.
  2. Na aba dos botões do painel, segure 1P Start ou 2P Start por 3 segundos.
  3. A tela pede um botão de cada vez (por exemplo, Button A). Aperte, no painel, o botão que você quer usar como A. Depois a tela pede o B, e assim até o H.
  4. Para mudar só alguns botões, mude só esses e aperte 1P Start. Os outros são ajustados sozinhos.
  5. Aperte 1P Start mais uma vez para salvar e voltar ao menu.

5.3 Ajustes do sistema (System Config)

Credit Setting

Free play é o modo família: sem moeda, e a saída do jogo é pelo menu de pausa. Opções com números (como 1:1 ou 2:1) ligam o modo moeda.

Exit Game Mode

Só no modo moeda. Escolhe como sair do jogo (veja abaixo).

Pause Menu

ON: o botão de pausa abre rápido o menu com a opção de sair. OFF: desligado.

Auto Exit

ON: se ninguém mexer por 3 minutos, a placa volta ao menu. OFF: desligado.

Select Game Mode

Só no modo moeda. Always: escolhe jogos sem moeda. With Coin: só depois de inserir moeda.

Quality Optimization

ON: melhora a imagem por programa. OFF: imagem original.

Scanning Line

ON: visual de monitor antigo. OFF: imagem ajustada para telas modernas (LCD).

Timer Mode

Home Game Timer Only: arcade por moeda, console por tempo. All Timer: tudo por tempo.

Game Time

No modo por tempo, define quantos minutos vale 1 moeda (de 1 a 60).

Gamepad Setting

Define quem é cada jogador (tabela mais abaixo).

Sair do jogo no modo moeda

Menu exit

Segure 1P Start por 3 segundos e escolha sair. As moedas que sobraram ficam guardadas para outro jogo.

1P start + coin

Segure 1P Start e insira 1 moeda. Você sai com 1 crédito válido para outro jogo.

Hold 1P start 3 sec.

Segure 1P Start por 3 segundos e saia direto. As moedas não ficam guardadas.

5.4 Ajustes dos jogos (Game Setting)

Na tela Game Setting, cada opção tem um botão colorido ao lado. Aperte o botão da cor da opção que você quer:

A Difficulty & Life

Escolha o jogo. A muda a dificuldade, B muda as vidas, C aplica o mesmo ajuste a todos. Alguns jogos não têm essas opções.

B Edit Games List

A esconde ou mostra o jogo (aparece um símbolo de proibido nos escondidos). B mostra todos. C faz o jogo escolhido abrir sozinho ao ligar e esconde os outros.

C Edit Favorite List

A marca o jogo com uma estrela. Os favoritos ficam no topo da lista, até 99 jogos. C tira todas as estrelas.

Para voltar, aperte 1P Start.

5.5 Contagem de moedas e senha (Book Keeping)

A placa conta todas as moedas inseridas e mostra o total em Total Coins. Para zerar a contagem ou trocar a senha:

  1. Digite a senha. Joystick para cima ou para baixo muda o número, e para a direita ou esquerda muda de casa.
  2. Escolha Coin Clear (zerar) ou Change Password (trocar a senha).
Senha de fábrica: 55555555
Se você trocar a senha, anote a nova em um lugar seguro.

5.6 Idioma, salvar e restaurar

Atenção
Quando aparecer SAVING... na tela, não desligue a energia. Espere a placa reiniciar sozinha.
Language

Inglês, espanhol ou coreano.

Boot Demo Movies

Com um jogo fixado como inicial, escolha OFF para pular o vídeo de abertura e entrar direto no jogo.

Save Setting

Aperte A, escolha YES e aperte A de novo. A placa reinicia e volta ao menu de jogos. Escolha NO para não guardar as mudanças.

Factory Setting

YES volta a todos os ajustes de fábrica. NO não muda nada.
